# 局域网手机语音测试

主机 Wi-Fi 地址当前为 `10.168.1.119`。手机需连接到与主机相同、允许设备互访的 WLAN。主机网页和 API 仍运行在本机 `127.0.0.1:3000/8000`；`scripts/lan_https_proxy.cjs` 通过 WLAN 地址提供 HTTPS，并把请求转给本机网页。

## 手机首次使用

1. 先在手机 Chrome 或 Edge 打开 `http://10.168.1.119:3444/health`。看到 `AI Interview Hub LAN connection OK` 才表示手机已连到主机；若打不开，核对手机 Wi-Fi 地址是否为 `10.168.1.x`，并确认路由器未启用访客网络或客户端隔离。
2. 打开 `http://10.168.1.119:3444/`，点击页面中的下载链接获取公开 CA 证书 `lan-ca.cer`。
3. 在 Android 设置中找到“安全与隐私 → 更多安全设置 → 加密与凭据 → 安装证书 → CA 证书”，选择刚下载的 `lan-ca.cer`。不同厂商的菜单名称可能略有差异。该证书只为本机局域网测试签发，30 天后过期；完成测试后可从“受信任的凭据 → 用户”中移除。
4. 在手机浏览器打开 **`https://10.168.1.119:3443/`**。地址栏应显示有效 HTTPS；若仍有证书警告，先检查证书安装，不要直接开始麦克风测试。
5. 登录，完成 3 秒录音回放，再录制并提交一题。报告生成后核对转写、声学值和评分。

## 主机运行与范围

- 主机当前已启动代理。重启后可在项目根目录运行 `node scripts/lan_https_proxy.cjs`；端口、网卡和证书目录从 `.env` 的 `LAN_*` 字段读取。
- Windows 防火墙只允许 WLAN 网卡本地子网访问 TCP `3443`（应用）和 `3444`（公开 CA 证书）。API 的 `8000` 端口保持本机访问。
- 如果主机 Wi-Fi IP 变化，需要重新生成包含新 IP 的服务器证书，更新 `.env` 的 `LAN_CERT_DIR` 并重建防火墙规则。
- USB 调试与 Radmin VPN 不参与此方案。
