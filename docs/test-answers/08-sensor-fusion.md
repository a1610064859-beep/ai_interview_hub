# 样本 08｜感知融合专项实践者

虚构背景：擅长传感器数据回放和困难天气场景分析，控制与量产决策经验相对有限。

## Q1 主回答

我是电子信息方向学生，在校企项目里负责相机、毫米波雷达和激光雷达数据的时间对齐与场景标注。我们发现夜间迎面车灯会造成相机目标置信度骤降，而融合轨迹仍短暂保持；我整理了连续帧和目标 ID，供算法同学验证跟踪逻辑。我想做测试，是因为对智驾系统而言，异常天气下的连续行为比晴天单帧指标更接近安全问题。

## Q2 主回答

对于偶发缺陷，我会保留传感器原始包、时间同步状态、软件版本、标定参数和融合输出，不只截取异常一帧。先排除数据丢包与时间戳错位，再用相同片段离线回放多次，记录触发条件和出现比例；如果路测条件不可控，就构造相近光照或遮挡用例。与开发讨论具体目标 ID 和帧范围，修复后用原片段及相邻场景做回归。

## Q3 主回答

HIL 适合让真实控制器在模拟闭环里接受可重复的目标、车辆动力学和故障输入，重点验证状态机、响应时延以及边界工况。实车道路测试检验真实传感器物理局限、标定变化、道路附着和交通互动。我的项目主要是离线传感器回放，不是完整 HIL；我会先用回放定位感知问题，再在台架和受控道路上验证整车影响，避免把离线通过当作放行证据。

## Q4 主回答

先保障车辆安全并锁定接管事件的时间轴。我会取接管前后的相机帧、雷达目标、点云、融合目标及置信度，检查漏检、鬼影、目标 ID 切换和定位偏移；再看规划轨迹、系统退出状态、横向控制请求与底盘实际转角。若原始感知稳定而融合目标突然跳变，优先查关联和时间同步；若规划正常但实际转角异常，则转给控制与底盘链路核实。初步 RCA 要附可重放片段，不能只给猜测。

## Q5 主回答

暴雨中，相机镜头水膜会造成局部模糊，激光雷达可能出现水滴回波和有效距离下降，毫米波雷达会有路面多径或地杂波；大雾中可见光对比度与激光回波都会衰减；强眩光会使相机过曝、目标框闪断。融合异常可能是虚假障碍物触发急刹、真实目标在多帧中断续消失，或跨传感器关联错误导致位置跳变。我会同时看单传感器召回、融合目标连续性及最终车辆行为，并区分天气强度和距离段。

## Q6 主回答

虽然我侧重感知，但急转向不是感知团队可以单独判断的。我会要求暂停放行，保存感知、定位、规划、控制和底盘的同步日志，先确认是不是虚假目标或车道边界跳变引发轨迹变化。若感知稳定，也不能因此宣布安全，应继续查控制请求和执行反馈。最终由测试、开发、功能安全和项目负责人根据根因、危害及回归证据作正式决策；我负责提供感知侧证据。

## 追问补充素材

- Q1：我负责时间对齐和失效场景标注，算法改动由开发完成。
- Q2：回放结果需记录标定、同步和模型版本，否则不可重复。
- Q3：离线回放、HIL 和实车验证的证据强度不同。
- Q4：查看同一目标的原始检测、融合跟踪和规划响应是否因果一致。
- Q5：雨雾等级、目标距离、相对速度和持续帧数应分组统计。
- Q6：即便感知无异常，也不能跳过底盘与控制链路排查。
