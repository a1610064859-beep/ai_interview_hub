# 《智驾未来·AI面试仓》命题05演示视频

成片：`智驾未来_AI面试仓_命题05演示.mp4`，196.24 秒，1920×1080 / 25 fps，H.264 视频和 AAC 音频，9,778,008 字节（9.33 MiB）。

这版按“选岗 → 面试舱逐题保存 → 声学与证据报告 → 成长记录 → 新生学习与路径 → 企业候选回看”讲述一次训练如何留下下一次练习的方向。十二个镜头以项目夜间主题的实际网页为主体；截图在 Microsoft Edge 中取得，面试和新生结果采用 1920×1080 视口以呈现完整标题、作答区和按钮，其余镜头采用 1600×900。网页截图完整放入画面。较长的报告分别展示总览与证据区域，企业页展示候选卡片与雷达预览。旁白使用 `zh-CN-XiaoxiaoNeural`、+8% 语速；镜头固定位置，仅做淡入淡出，底部烧录中文字幕。

## 画面来源与口径

- 报告总览和证据来自已有会话 #6 / 报告 #4，综合评定 79.2；声学观测为语速 178 字/分、停顿 2.3 次/分、填充词 2.6 次/分。
- 成长页展示同一学生、同一岗位的两次已完成训练。页面只计算两次都有效的专业匹配度、逻辑结构和岗位素养，三项模型评分均分为 75.0 → 94.2；文本训练缺失的表达流畅度不混算。变化仅是模型评分观测，不代表真实能力提升幅度。
- 新生路径画面是页面实际生成的静态回退结果，展示岗位地图与进入训练的入口。
- 企业画面是实际运行的候选列表、岗位权重和雷达预览；候选记录可回到原报告。它是分段页面演示，不宣称已录下三端连续操作。
- 面试舱取图从岗位选择开始，在 Edge 里完成设备自检并创建临时会话，因此画面是正常第 1 题，没有恢复提示。取图使用数据库快照与虚拟麦克风；`capture_edge.cjs` 只为本地取图模拟 `/api/auth/me` 身份，并从项目 API 的 `/api/students` 响应中选择对应演示学生。问题、报告和成长数据仍由运行中的项目 API 提供。截图不充当登录或完整语音链路验收证据。

## 源文件

`video_source/capture_edge.cjs` 在 Microsoft Edge 中打开本地页面，生成 `video_assets/edge_*.png`；命令行可指定要重拍的文件名。`video_source/make_video.py` 负责分镜、旁白、字幕和 FFmpeg 合成。旁白文本、SRT 字幕、分镜与素材哈希、媒体探针结果分别保存在 `video_source/narration_*.txt`、`智驾未来_演示字幕.srt`、`storyboard.json`、`video_probe.json`。制作前需在本地启动项目，并用 SQLite 在线备份创建含 WAL 数据的数据库快照；取图脚本通过 `VIDEO_APP_URL` 指向项目地址，通过 `PLAYWRIGHT_MODULE` 指向可用的 Playwright 包。

字幕按每段旁白的实测时长分配到句段，不使用词级时间戳。使用带 Pillow 的 Python 运行 `make_video.py --prepare` 和 `--render`；语音合成调用 `edge_tts`。如项目虚拟环境的 Python 路径已失效，可用 `VIDEO_TTS_PYTHON` 指向兼容的 Python 可执行文件。
