# 《智驾未来·AI面试仓》命题05演示视频

成片：`智驾未来_AI面试仓_命题05演示.mp4`，194.92 秒，1920×1080 / 25 fps，H.264 视频和 AAC 音频，11,003,299 字节（10.49 MiB）。

这版按“选岗 → 面试舱逐题保存 → 声学与证据报告 → 成长记录 → 新生学习与路径 → 企业候选回看”讲述一次训练如何留下下一次练习的方向。十二个镜头以项目夜间主题的实际网页为主体；Edge 以 1600×900 视口打开本地运行的项目，截图完整放入画面，不再裁切底部，也不缩进右侧窄框。较长的报告分别展示总览与证据区域，企业页展示候选卡片与雷达预览。旁白改为更有起伏的叙事文本，使用 `zh-CN-XiaoxiaoNeural`、+8% 语速；画面做轻微漂移与淡入淡出，底部烧录中文字幕。

## 画面来源与口径

- 报告总览和证据来自已有会话 #6 / 报告 #4，综合评定 79.2；声学观测为语速 178 字/分、停顿 2.3 次/分、填充词 2.6 次/分。
- 成长页当前只有一次训练，画面明确显示“不可直接比较”，不绘制虚构的上升趋势。
- 新生路径画面是页面实际生成的静态回退结果，展示岗位地图与进入训练的入口。
- 企业画面是实际运行的候选列表、岗位权重和雷达预览；候选记录可回到原报告。它是分段页面演示，不宣称已录下三端连续操作。
- 面试舱取图使用数据库副本中的临时会话；`capture_edge.cjs` 仅为本地取图模拟 `/api/auth/me` 的角色响应，业务页面和报告数据仍由运行中的项目 API 提供。截图不充当登录或完整语音链路验收证据。

## 源文件

`video_source/capture_edge.cjs` 在 Microsoft Edge 中打开本地页面，生成 `video_assets/edge_*.png`。`video_source/make_video.py` 负责分镜、旁白、字幕和 FFmpeg 合成。旁白文本、SRT 字幕、分镜与素材哈希、媒体探针结果分别保存在 `video_source/narration_*.txt`、`智驾未来_演示字幕.srt`、`storyboard.json`、`video_probe.json`。制作前需在本地启动项目，并准备数据库副本；取图脚本通过 `VIDEO_APP_URL` 指向项目地址，通过 `PLAYWRIGHT_MODULE` 指向可用的 Playwright 包。

字幕按每段旁白的实测时长分配到句段，不使用词级时间戳。使用带 Pillow 的 Python 运行 `make_video.py --prepare` 和 `--render`；语音合成调用项目虚拟环境中的 `edge_tts`。
