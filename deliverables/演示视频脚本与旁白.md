# 《智驾未来·AI面试仓》演示视频脚本

最终成片约 195 秒，12 个镜头。旁白全文以 `video_source/narration_00.txt` 至 `narration_11.txt` 为准；`storyboard.json` 记录每段实际时长和素材哈希，`智驾未来_演示字幕.srt` 对应最终合成版本。

| 镜头 | 页面画面 | 叙事重点 |
| --- | --- | --- |
| 01 开场 | Edge 中的岗位首页 | 一次面试不应只留一个分数 |
| 02 选岗 | 智驾、三电种子岗位卡片 | 题目进入真实岗位语境 |
| 03 面试舱 | 当前问题、进度、语音和文本入口 | 一题一存，刷新续答 |
| 04 声学 | 报告中的表达流畅度卡片 | 语速、停顿和填充词可观察 |
| 05 报告 | 综合分与四维雷达图 | 分数之外解释原因 |
| 06 证据 | 维度卡片与改进建议 | 原话引用与下一步练习 |
| 07 成长 | 同人同岗成长页 | 历史可回看，一次训练不伪造趋势 |
| 08 学习 | 新生学习菜单 | 听题、讲真实经历、诚实回应 |
| 09 路径 | 新生岗位地图与进入训练入口 | 从兴趣走向可执行的准备路径 |
| 10 企业 | 候选卡片、权重和雷达预览 | 加权排序可回到原报告 |
| 11 链路 | 面试舱页面 | 前后端编排、语音与逐题落库 |
| 12 结尾 | 能力报告主画面 | 让每次回答成为下一步 |

画面来自 Microsoft Edge 的 1600×900 完整视口截图，以原比例居中放入 1080p 视频。旁白采用更接近现场讲述的提问、转折与具体例子，不把画面中的一次训练说成已证明能力提升，也不把分段截图说成连续操作录像。
